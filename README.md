GROUNDED

An AI augmented day planner and habit builder. 

This app is designed to do the following:
1. List all tasks to be performed within a day
2. Block certain chosen apps that prove to be an obstacle to productivity. You may also choose to block certain functionality from
   certain apps.
3. The apps will remain unblocked until and unless the listed tasks have been completed. The app will use a verification system to 
   ensure there will be no cheating. 
4. The user can choose to allow 'breaks' - downtime of maximum 10 minues where the user can use the blocked apps.
5. Utilize AI to make a schedule detailing the tasks to be done. This AI will serve as a day planner.
6. Utilize AI to make a habit plan that helps you achieve 'X' goal in 'Y' time.
